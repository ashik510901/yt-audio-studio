# 🎧 YT Audio Studio — Web Version

YouTube লিংক থেকে অডিও (MP3 / M4A / OPUS / FLAC / WAV) তৈরির ওয়েব অ্যাপ। সব প্রসেসিং সার্ভারে হয়।
দুই মোডে চলে: **ক্লাউড মোড** (GitHub + Streamlit Community Cloud, ফ্রি) এবং **লোকাল Windows মোড** (নিজের পিসিতে, বাসার IP দিয়ে)।

---

## 🧭 `HTTP Error 403: Forbidden` — কারণ ও সমাধান (সংক্ষেপে)

লক্ষণ: লিংক, টাইটেল, থাম্বনেইল, সময় ঠিকই আসে; কিন্তু **Convert** চাপলে `unable to download video data: HTTP Error 403: Forbidden`।

এর মানে তথ্য আনা (প্রিভিউ) পার হয়েছে, কিন্তু আসল অডিও-স্ট্রিমের লিংকে YouTube 403 দিয়েছে। সম্ভাব্য কারণ (যে কোনোটা বা একাধিক):

| # | কারণ | ব্যাখ্যা |
|---|---|---|
| 1 | **PO Token / SABR** | ২০২৬-এ YouTube বহু ক্লায়েন্টে (web, mweb, ios, android…) ডাউনলোড-লিংকে PO Token চাপাচ্ছে বা SABR স্ট্রিমিং বাধ্যতামূলক করছে। টোকেন ছাড়া লিংকে 403 আসে। yt-dlp-র সরকারি গাইডে এটাই বলা আছে। আগস্ট ২০২৬-এ `android_vr` ক্লায়েন্টেও ব্যাপক 403 হয়েছিল; সেটা yt-dlp **2026.08.19**-এ ঠিক হয়েছে। |
| 2 | **ক্লাউড সার্ভারের IP** | Streamlit Cloud ডেটাসেন্টারে চলে; YouTube এই ধরনের IP-কে প্রায়ই ব্লক বা সন্দেহ করে। |
| 3 | **পুরনো yt-dlp** | 2026.08.19-এর আগের সংস্করণে ওই 403 বাগ ছিল। |
| 4 | **JavaScript রানটাইম (Deno) নেই** | না থাকলে কিছু ফরম্যাট মেলে না। অ্যাপ নিজে Deno নামিয়ে নেয়; Help ট্যাবের Diagnostics-এ দেখা যায় পাওয়া গেছে কি না। |
| 5 | **এই প্রজেক্টের আগের কোডের একটা ভুল (ঠিক করা হয়েছে)** | আগে তথ্য আনার সময় `skip=hls,dash` দেওয়া ছিল। কিন্তু HLS-ই PO Token ছাড়া চলা পথ হতে পারে। তাই ওটা সরিয়ে ফেলা হয়েছে। এছাড়া আগে শুধু একটা ডাউনলোড পদ্ধতি ছিল; ব্যর্থ হলে আর কিছু চেষ্টা হতো না। |

FFmpeg/কনভার্ট এই সমস্যার কারণ **নয়**; 403 আসে ডাউনলোডের ধাপে, কনভার্টের আগেই।

### এখন অ্যাপ যা করে
1. একে একে কয়েকটি **ডাউনলোড পদ্ধতি** চেষ্টা করে: `default` → `android` → `tv` → `web_embedded` → `hls` (HLS থেকে শুধু অডিও নেয়) → `hls-mweb`।
2. কোনো পদ্ধতিতে লিংকে 403 পেলে সঙ্গে সঙ্গে পরেরটায় যায় (সময় নষ্ট করে না)।
3. যেটা কাজ করে সেটা মনে রাখে এবং পরেরবার আগে চেষ্টা করে।
4. সব ব্যর্থ হলে প্রতিটি পদ্ধতির কারণসহ তালিকা দেখায়।
5. **Help → 🩺 Diagnostics** কিছু ডাউনলোড না করে বলে দেয় কোন পদ্ধতিতে কী হচ্ছে, আর সিদ্ধান্ত দেয়: IP ব্লক, PO Token, পুরনো yt-dlp, Deno নেই ইত্যাদি।

### কী করবেন (ধাপে ধাপে)
1. এই নতুন ফাইলগুলো GitHub-এ আপলোড করুন (পুরনোগুলো বদলে)। `requirements.txt` বদলেছে, তাই Streamlit নতুন yt-dlp বসাবে। তারপর **Manage app → Reboot**।
2. অ্যাপ খুলে চিপে `yt-dlp` সংস্করণ দেখুন (**2026.08.19 বা নতুন** হতে হবে) এবং `Deno ✔` আছে কি না দেখুন।
3. **Help ট্যাব → Diagnostics** চালান (একটা ছোট ভিডিওর লিংক দিয়ে):
   - ✔ দেখালে: কাজ করা পদ্ধতি দেখাবে। Convert চাপলে ওটাই ব্যবহার হবে।
   - ⛔ ও "ডেটাসেন্টার IP" দেখালে: সমস্যা ক্লাউড IP-এর।
4. **তুলনা:** একই ভিডিও নিজের পিসিতে চালান (নিচে "লোকাল Windows মোড")। লোকালে চললে আর ক্লাউডে না চললে নিশ্চিত যে সমস্যা ক্লাউড IP-এর।
5. ক্লাউডে ব্যর্থ হলে `YT_COOKIES` দিয়ে চেষ্টা করুন (নিচে দেখুন)।

### সৎ সীমাবদ্ধতা
- ক্লাউড IP ব্লক হলে কুকিও সবসময় কাজ করে না। **PO Token Provider (bgutil)** চালাতে আলাদা সার্ভার/Node দরকার; ফ্রি Streamlit Cloud-এ এটা বাস্তবসম্মত নয়, তাই যোগ করা হয়নি। yt-dlp-র একটা রিপোর্টেও আছে যে bgutil দিয়েও SABR সমস্যা মেটেনি।
- ফ্রি ও নির্ভরযোগ্য সমাধান: **বাসার IP** (লোকাল মোড, অথবা বাসায় সবসময় চালু থাকা পুরনো ল্যাপটপ/Raspberry Pi)। রেসিডেনশিয়াল প্রক্সি কাজ করে, কিন্তু সেটা পেইড।
- YouTube প্রায়ই বদলায়। আজ কাজ করা পদ্ধতি কাল ভাঙতে পারে; তখন yt-dlp আপডেট + Reboot করুন।

## 🖥 লোকাল Windows মোড (নিজের পিসিতে)

বাসার IP ব্যবহার হয়, তাই ক্লাউডের IP-ব্লক সমস্যা থাকে না। ক্লাউড ও লোকাল **একই কোড**, `APP_MODE` দিয়ে মোড আলাদা হয়।

1. Python 3.11+ ইনস্টল করুন ([python.org](https://www.python.org/downloads/)), ইনস্টলের সময় **Add python.exe to PATH** টিক দিন।
2. প্রজেক্ট ফোল্ডারে **`run_local_windows.bat`** ডাবল ক্লিক করুন। এটা নিজে venv বানায়, প্যাকেজ ইনস্টল করে, FFmpeg না থাকলে `winget` দিয়ে ইনস্টল করার চেষ্টা করে (ইনস্টলের পর উইন্ডো বন্ধ করে আবার চালান), তারপর অ্যাপ খোলে।
3. লোকাল মোডে বাড়তি সুবিধা:
   - ভিডিওর সর্বোচ্চ দৈর্ঘ্য ১২ ঘণ্টা।
   - Settings → Advanced-এ **ব্রাউজার-কুকি** (firefox / edge / chrome / brave)। নিজের পিসির ব্রাউজারের YouTube সেশন ব্যবহার করে; কুকি ফাইলে সেভ হয় না। **Firefox সবচেয়ে নির্ভরযোগ্য**; নতুন Chrome/Edge-এ কুকি পড়া ব্যর্থ হতে পারে। ব্রাউজার বন্ধ করে নিন।
4. সমস্যা হলে **`diagnose_local_windows.bat`** চালান: লিংক পেস্ট করলে টার্মিনালে একই Diagnostics রিপোর্ট দেখাবে। কমান্ডে: `python diagnose.py "<লিংক>" --browser firefox`।

## 🚀 ক্লাউডে ডিপ্লয়

### ধাপ ১: GitHub-এ আপলোড
1. [github.com](https://github.com)-এ **New repository** বানান (নিজের জন্য হলে **Private**)।
2. **Add file → Upload files**-এ উপরের সব ফাইল (`.streamlit` ফোল্ডারসহ) দিন, তারপর **Commit changes**।
   - ZIP আপলোড করা যায় না; আগে ZIP খুলুন।
   - `.streamlit` ডট-ফোল্ডার Windows-এ লুকানো থাকতে পারে (View → Hidden items)।
   - আপলোডের পর রিপোজিটরিতে `.streamlit/config.toml` পথটা দেখা যাচ্ছে কি না মিলিয়ে নিন।

কমান্ড দিয়ে:
```bash
git init && git add . && git commit -m "YT Audio Studio web"
git branch -M main
git remote add origin https://github.com/আপনার-নাম/yt-audio-web.git
git push -u origin main
```

### ধাপ ২: Streamlit Community Cloud
1. [share.streamlit.io](https://share.streamlit.io)-এ GitHub দিয়ে লগইন করুন।
2. **Create app / New app** → রিপোজিটরি বেছে নিন (বোতামের নাম বদলাতে পারে)।
3. Repository: `আপনার-নাম/yt-audio-web`, Branch: `main`, Main file path: **`streamlit_app.py`**।
   **Advanced settings → Python version:** `3.12` (বা 3.11/3.13)।
4. **Advanced settings → Secrets**-এ:
   ```toml
   APP_PASSWORD = "আপনার-গোপন-পাসওয়ার্ড"
   ```
   (`CHANGE_ME` দিয়ে শুরু করবেন না; ওই উদাহরণ-মান থাকলে অ্যাপ নিরাপত্তার কারণে চালু হবে না।)
5. **Deploy**। প্রথমবার কয়েক মিনিট লাগে; এরপর অ্যাপ নিজে Deno নামিয়ে নেয়।

## 🧠 ফ্রি সার্ভারে CPU/RAM সাশ্রয়

Streamlit Community Cloud-এর সীমা আনুমানিক ২ CPU কোর ও ~২.৭ GB RAM; ১২ ঘণ্টা কেউ না ঢুকলে অ্যাপ ঘুমায়।
- একসাথে একটাই ভারী কাজ; ফাইল ডিস্কে স্ট্রিম হয়; মূল স্ট্রিম ফাইল কনভার্টের পরেই মুছে যায়।
- প্রতি ভিডিও ডিফল্টে সর্বোচ্চ ৩ ঘণ্টা (`MAX_MINUTES`); সেশনে সর্বোচ্চ ৩টি ফাইল / ~৩০০ MB।
- ২ ঘণ্টার পুরনো অস্থায়ী ফাইল নিজে মুছে যায়।
- HLS ফলব্যাকে 144p মিশ্র স্ট্রিম নামে (ঘণ্টায় প্রায় ৭৫ MB), তাই লম্বা ভিডিওতে ডাউনলোড বেশি লাগতে পারে।

## 🔐 সিক্রেটস (সবই ঐচ্ছিক) — GitHub-এ কখনো দেবেন না

App → **Settings → Secrets**-এ দিন। উদাহরণ: `.streamlit/secrets.toml.example`।

| নাম | কাজ |
|---|---|
| `APP_PASSWORD` | অ্যাপে ঢোকার পাসওয়ার্ড (**দিতে বলব**) |
| `MAX_MINUTES` | প্রতি ভিডিওর সর্বোচ্চ দৈর্ঘ্য (মিনিটে); ডিফল্ট ক্লাউডে 180, লোকালে 720 |
| `TIMEZONE` | তারিখের টাইমজোন; ডিফল্ট `Asia/Dhaka` |
| `YT_COOKIES` | `cookies.txt`-এর পুরো লেখা |
| `YT_PROXY` | নিজের কোনো প্রক্সি থাকলে |

### কুকি দেওয়ার নিয়ম (ক্লাউডে 403/বট-চেক হলে)
1. **আলাদা একটি নতুন Google অ্যাকাউন্ট** ব্যবহার করুন (মূল অ্যাকাউন্ট নয়, ফ্ল্যাগ হতে পারে)।
2. প্রাইভেট/ইনকগনিটো উইন্ডোতে ওই অ্যাকাউন্টে YouTube-এ লগইন করুন।
3. কুকি-এক্সপোর্ট এক্সটেনশন দিয়ে `youtube.com`-এর কুকি **Netscape ফরম্যাটে** সেভ করুন, তারপর উইন্ডো বন্ধ করুন।
4. `cookies.txt`-এর পুরো লেখা (প্রথম লাইন `# Netscape HTTP Cookie File` সহ) Secrets-এ `YT_COOKIES = """..."""` হিসেবে বসান।
5. **কুকি GitHub-এ আপলোড করবেন না।** কুকি পাসওয়ার্ডের মতো: যে পায় সে ওই অ্যাকাউন্টে ঢুকতে পারে। মেয়াদ শেষ হলে আবার দিন।
