# 🎧 YT Audio Studio — Web Version

YouTube লিংক থেকে অডিও (MP3 / M4A / OPUS / FLAC / WAV) তৈরি করার ওয়েব অ্যাপ। সব প্রসেসিং সার্ভারে হয়, আপনার কম্পিউটারে শুধু ব্রাউজার লাগে। GitHub + Streamlit Community Cloud দিয়ে সম্পূর্ণ ফ্রিতে হোস্ট করা যায়।

---

## ⚠️ শুরুতেই জেনে রাখুন (গুরুত্বপূর্ণ)

**YouTube ক্লাউড সার্ভারের IP প্রায়ই ব্লক করে।** Streamlit Community Cloud একটি ক্লাউড/ডেটাসেন্টার সার্ভার, তাই ডাউনলোডের সময় এই এরর আসতে পারে:

> `Sign in to confirm you're not a bot`

- এটা কোডের ভুল নয়; YouTube সার্ভারের IP দেখেই আটকায়। আপনার বাসার নেট থেকে একই কোড ঠিকই চলে।
- কুকি দিলে (নিচে দেখুন) কখনো কখনো কাজ করে, কিন্তু **নিশ্চয়তা নেই**। অনেকের অভিজ্ঞতায় ক্লাউড IP-তে কুকি দিয়েও ব্লক থাকে।
- ফ্রি ও নির্ভরযোগ্য সমাধান নেই। রেসিডেনশিয়াল প্রক্সি কাজ করে, কিন্তু সেটা পেইড, তাই এখানে রাখা হয়নি।
- এই প্রজেক্ট দিয়ে আগে ডিপ্লয় করে **একটা ছোট ভিডিও দিয়ে পরীক্ষা করুন**। চললে ভালো; না চললে অ্যাপে এই কারণটাই দেখাবে।

যদি কাজ না করে, বিকল্প: আগের ডেস্কটপ সফটওয়্যারটা বাসার কম্পিউটারে চালানো, অথবা বাসায় সবসময় চালু থাকে এমন কোনো ডিভাইসে (পুরনো ল্যাপটপ/Raspberry Pi) এটাই চালানো, কারণ বাসার IP ব্লক হয় না।

## 📁 ফাইলের তালিকা

```
আপনার-রিপোজিটরি/
├── streamlit_app.py            ← ওয়েব UI (মূল ফাইল)
├── core.py                     ← ইঞ্জিন: ডাউনলোড, MP3 কনভার্ট, কভার আর্ট, ট্যাগ
├── requirements.txt            ← Python লাইব্রেরি
├── packages.txt                ← সার্ভারের প্রোগ্রাম (ffmpeg)
├── README.md                   ← এই ফাইল
├── .gitignore                  ← গোপন তথ্য/অডিও ফাইল GitHub-এ যাওয়া আটকায়
└── .streamlit/
    ├── config.toml             ← থিম ও সার্ভার সেটিংস
    └── secrets.toml.example    ← সিক্রেটসের উদাহরণ (আসল সিক্রেট এখানে দেবেন না)
```

> ফাইলগুলো আলাদা আলাদা ডাউনলোড করলে `config.toml` ও `secrets.toml.example` কে অবশ্যই **`.streamlit`** নামের ফোল্ডারের ভেতরে রাখবেন। বাকিগুলো সরাসরি রিপোজিটরির মূল জায়গায় থাকবে।

## 🚀 ডিপ্লয় করার ধাপ

### ধাপ ১: GitHub-এ আপলোড
1. [github.com](https://github.com)-এ অ্যাকাউন্ট খুলুন এবং **New repository** বানান। নাম যেমন `yt-audio-web`। নিজের জন্য ব্যবহার করলে **Private** বেছে নিন।
2. রিপোজিটরিতে **Add file → Upload files** চাপুন এবং উপরের সব ফাইল (`.streamlit` ফোল্ডারসহ) টেনে ছেড়ে দিন, তারপর **Commit changes**।
   - ZIP আপলোড করা যায় না; আগে ZIP খুলে ভেতরের ফাইল/ফোল্ডার আপলোড করুন।
   - `.streamlit` ডট-ফোল্ডার ফাইল ম্যানেজারে লুকানো থাকতে পারে (Windows: View → Hidden items চালু করুন)।
   - আপলোডের পর রিপোজিটরিতে `.streamlit/config.toml` পথটা দেখা যাচ্ছে কি না মিলিয়ে নিন।

অথবা কমান্ড দিয়ে:
```bash
git init
git add .
git commit -m "YT Audio Studio web"
git branch -M main
git remote add origin https://github.com/আপনার-নাম/yt-audio-web.git
git push -u origin main
```

### ধাপ ২: Streamlit Community Cloud-এ ডিপ্লয়
1. [share.streamlit.io](https://share.streamlit.io) এ GitHub দিয়ে লগইন করুন (প্রাইভেট রিপো হলে Streamlit-কে GitHub-এ অ্যাক্সেস দিন)।
2. **Create app** (বা **New app**) চাপুন এবং **Deploy a public app from GitHub / Use existing repo** ধরনের অপশন বেছে নিন (বোতামের নাম বদলাতে পারে)।
3. Repository: `আপনার-নাম/yt-audio-web`, Branch: `main`, Main file path: **`streamlit_app.py`**।
   **Advanced settings → Python version:** `3.12` (বা 3.11/3.13) বেছে নিন।
4. **Advanced settings → Secrets** এ নিচের লেখা বসান (পাসওয়ার্ড বদলে নিন):
   ```toml
   APP_PASSWORD = "আপনার-গোপন-পাসওয়ার্ড"
   ```
   (`CHANGE_ME` দিয়ে শুরু করবেন না, ওই উদাহরণ-মান থাকলে অ্যাপ নিরাপত্তার কারণে চালু হবে না।)
5. **Deploy** চাপুন। প্রথমবার লাইব্রেরি ও FFmpeg ইনস্টল হতে কয়েক মিনিট লাগে। এরপর অ্যাপ চালু হলে প্রথমবার JavaScript রানটাইম (Deno, YouTube-এর জন্য দরকার) নিজে নেমে আসবে।

### ধাপ ৩: ব্যবহার
1. অ্যাপের লিংকে ঢুকে পাসওয়ার্ড দিন।
2. লিংক পেস্ট করুন। ভিডিওর সময় সঙ্গে সঙ্গে সবুজ বক্সে দেখাবে।
3. **Convert to Audio** চাপুন, তারপর নিচ থেকে ফাইল ডাউনলোড করুন।

## 🧠 ফ্রি সার্ভারের জন্য CPU/RAM সাশ্রয়

Streamlit Community Cloud-এর সীমা আনুমানিক ২ CPU কোর ও ~২.৭ GB RAM (সীমা বদলাতে পারে), আর ১২ ঘণ্টা কেউ না ঢুকলে অ্যাপ ঘুমিয়ে যায়। তাই:

- একসাথে একটাই ভারী কাজ চলে; বাকিরা সারিতে অপেক্ষা করে।
- ফাইল ডিস্কে স্ট্রিম হয়, পুরোটা RAM-এ রাখা হয় না। মূল স্ট্রিম ফাইল কনভার্টের পরেই মুছে যায়।
- প্রতি ভিডিও ডিফল্টে সর্বোচ্চ **৩ ঘণ্টা** (`MAX_MINUTES` দিয়ে বদলানো যায়)।
- সেশনে সর্বোচ্চ ৩টি ফাইল / ~৩০০ MB রাখা হয়, বাকি পুরনোগুলো নিজে মুছে যায়। ২ ঘণ্টার পুরনো অস্থায়ী ফাইলও মুছে যায়।
- ডাউনলোড বাটন ফাইলটা RAM-এ পড়ে: ৩ ঘণ্টার 192 kbps MP3 প্রায় ২৫০ MB। এর চেয়ে লম্বা ভিডিও বা বেশি ফাইল একসাথে রাখবেন না।

## 🔐 সিক্রেটস (সবই ঐচ্ছিক)

App → **Settings → Secrets** এ দিন। উদাহরণ `.streamlit/secrets.toml.example` ফাইলে আছে।

| নাম | কাজ |
|---|---|
| `APP_PASSWORD` | অ্যাপে ঢোকার পাসওয়ার্ড। **দিতে বলব**, নইলে লিংক পেলে যে কেউ আপনার সার্ভার ব্যবহার করবে। |
| `MAX_MINUTES` | প্রতি ভিডিওর সর্বোচ্চ দৈর্ঘ্য (মিনিটে), ডিফল্ট 180 |
| `TIMEZONE` | তারিখের টাইমজোন, ডিফল্ট `Asia/Dhaka` |
| `YT_COOKIES` | `cookies.txt`-এর পুরো লেখা (YouTube ব্লক করলে চেষ্টা করার জন্য) |
| `YT_PROXY` | নিজের কোনো প্রক্সি থাকলে |

### কুকি দেওয়ার নিয়ম (ব্লক হলে)
1. **আলাদা একটি নতুন Google অ্যাকাউন্ট** ব্যবহার করুন, নিজের মূল অ্যাকাউন্ট নয়, কারণ অ্যাকাউন্ট ফ্ল্যাগ হতে পারে।
2. ব্রাউজারের প্রাইভেট/ইনকগনিটো উইন্ডোতে YouTube-এ ওই অ্যাকাউন্টে লগইন করুন।
3. কুকি এক্সপোর্টের একটা এক্সটেনশন দিয়ে (যেমন "Get cookies.txt LOCALLY") `youtube.com`-এর কুকি **Netscape ফরম্যাটে** সেভ করুন, তারপর উইন্ডো বন্ধ করুন।
4. `cookies.txt` ফাইলের পুরো লেখা Secrets-এ বসান, প্রথম লাইন `# Netscape HTTP Cookie File` সহ:
   ```toml
   YT_COOKIES = """# Netscape HTTP Cookie File
   .youtube.com	TRUE	/	TRUE	...	...	...
   """
   ```
5. **কুকি কখনো GitHub-এ আপলোড করবেন না**, শুধু Secrets-এ দিন। কুকির মেয়াদ শেষ হলে আবার দিতে হবে।
